Performa Mahasiswa
===================

Computer-based exam and academic performance tracking system for a university, built with CodeIgniter.

Manages departments, courses, classes, lecturers and students, then handles exams end to end: question bank, exam sessions per class, and results per student.

Features
--------

- Department, course, class and semester management
- Lecturer and student records, assigned per class
- Exam question bank
- Exam sessions (CBT) and per-student results

Stack
-----

PHP, CodeIgniter, MySQL
